# 项目助手精简版能力边界

本配置用于验证未来工作台的项目助手闭环，UI 与聊天流程仍来自锁定的 T3 Code v0.1.1。本轮收起功能入口与新增执行能力，保留上游源码和依赖，不以删除代码或缩减构建体积作为目标。

## 使用范围

| 模块 | 精简版范围 |
| --- | --- |
| 项目与权限 | 登录、身份、项目/环境、可见性与既有资料授权保留；CPA 由宿主配置，运行权限固定 |
| 输入与执行 | 中文输入、CPA 模型及对应思考强度选择、附件与资料上下文、原生技能搜索/选择/说明及真实调用、草稿/暂存及冲突恢复、流式回复、工具详情、提问/授权、引导/排队、队列编辑/取消、停止、手动 `/compact`、`/model` |
| 阅读与恢复 | Markdown、代码高亮、滚动锚定、历史分页/搜索、断线重连、现有产物与文件下载 |
| 会话管理 | 新建、重命名、置顶、排序、归档/取消归档、删除确认；旧稍后提醒/已处理记录仍可阅读及恢复 |
| 常规设置 | 发送快捷键、后续输入的引导/排队偏好；技能库入口；管理员集中管理、版本校验及助手/项目分配；默认模型/权限/版本只读，实际模型与强度在输入区选择 |
| 外观设置 | 浅色/深色/跟随系统、配对主题、本地新建/编辑/复制/导入/导出、对比度、玻璃透明度、对话宽度、适用字体与字号、字体平滑、换行、数学公式、界面动效与面板动画时长 |
| 暂停新增 | 计划及执行计划、分支对话、历史编辑/回退、子智能体、交互式 HTML/MCP Apps、稍后提醒/已处理自动化、高级发送方式、用量面板、自定义快捷键、系统通知和调试入口 |

旧计划、分支、子任务、HTML 与工具记录仍可阅读。关闭交互式产物的新调用和回传，不删除已保存的静态内容。项目资料读取、Markdown/PDF 报告与附件下载保留。在线主题市场受现有同源 CSP 限制，本轮不展示，也不放宽 CSP。

全局导航使用全宽 `52px` 顶部项目选择，桌面问答、工作区、部署发布使用 T3 原生 `ToggleGroup`，“更多功能”使用可搜索 `Combobox`，窄屏合并为“切换模块”。常用按钮和菜单共用授权功能注册表，当前只列已闭环的问答、工作区、部署发布、技能库及常规、外观、归档；部署入口继续受项目角色约束。未来 MCP、插件完成权限与业务闭环后再注册，不展示未实现的占位入口。

设置导航只开放常规、外观、归档；开源许可证保留底部入口。设置页同样显示顶部项目选择，切项目时留在当前设置页，返回业务区域时使用当前项目与权限。自定义快捷键编辑器关闭，T3 核心快捷键及提示保留。外观里的终端、差异对比、工作区上下文和环境身份装饰不适用于本 Demo，不展示。

技能是精简版保留的核心能力。顶部“更多功能 → 技能库”（`/skills`）统一管理完整技能包，常规设置提供入口。管理员可导入 `SKILL.md`、ZIP 或公开 HTTPS Git 固定提交，并将指定版本分配给业务助手或项目，选择内部／外部工作区范围。同一技能的项目分配优先于助手分配；项目显式停用不回退助手。

对话沿用 T3 原生 `$` 搜索、标签、说明预览及真实技能输入。可用目录由服务器依据当前项目、助手、工作区和成员身份生成；全局原生目录为空。参考资料通过现有授权文件工具按目录发现和读取。首次执行固定技能版本，新版本只影响新对话；停用或撤回会拒绝旧会话后续轮次并提示新建对话，已开始本轮和历史保留。删除中央技能前必须撤回所有分配；不可变包保留，不改写历史。

内置技能及原 JSON 注册表首次自动迁入；显式空库保持为空，既有自定义包默认仅内部。完整文件保存不代表运行条件就绪：脚本、依赖或命令执行技能显示“未就绪”，当前不允许分配或调用，不自动安装依赖或增加工具权限。目录管理参考 Skills Manager 1.43.0 固定提交，界面仍仅用锁定的 T3；具体复用和适配差异见 [来源说明](../vendor/skills-manager/README.md)。

模型与思考强度使用 T3 原生选择器、草稿保存、`/model` 及快捷键流程。默认仍为 `grok-4.6`；可选目录及每个模型的思考档位来自已配置 CPA 的能力接口，图像/视频生成型号不进入对话选择器。worker 启动时同步并缓存能力元数据，同一 CPA 短暂不可达时可回用上次成功目录；缓存不含密钥。服务端和原生请求均校验模型与思考档位，不能从浏览器切换运行器、接口或权限，也不能把所选模型强制改回默认。模型名称与实际返回型号之间的上游别名映射沿用 CPA 配置；目录声明的档位不等同于每个上游型号的推理效果均已测量。

普通对话不显示空详情；仅有实际历史关联时显示查看入口。没有资料预览时隐藏右侧面板按钮。只读历史使用阅读提示与新建对话入口，不显示无法发送的编辑器。锁定的环境、可见范围及唯一 Agent 以文字显示；新建对话仍可选择环境与范围。不提供未适配的 T3 提示词分享链接和普通用户对话 ID 复制入口。

“外观 → 动画 → 界面动效”默认跟随系统，也可显式开启或关闭。显式开启允许 Windows 关闭动画而工作台仍播放原生等待与界面动效；关闭时不播放动效。设置沿用当前账号在此浏览器中的偏好存储，刷新保留；“恢复默认”恢复跟随系统。面板动画时长独立设置，默认 0 ms，不因开启动效自动增加布局动画。后台、不可见活动仍暂停，高对比度模式仍保留可读的静态状态。

## 能力与偏好

`AUTOOPS_DEMO_PROFILE=project-assistant-lite-v1` 是部署时显式选择。`agent-demo/t3-adapters/product-profile.mjs` 是服务端能力与有效设置的来源；宿主 bootstrap 将配置传给界面，RPC、HTTP/MCP、原生 Codex 配置同时约束执行。不能通过旧客户端、深链或隐藏入口发起已关闭能力。

精简版强制按已完成段落流式显示，关闭自动恢复受限轮次、自动稍后提醒、自动整理、重启后继续执行和 Claude 空闲压缩。删除始终确认。覆盖的是有效设置，不改写用户原有隐藏偏好；外观、发送快捷键和后续输入偏好按用户选择生效。“恢复默认”仅恢复精简版开放的可编辑字段，不清空暂存、主题库或隐藏偏好。

`t3-demo-full-v1` 保留此前已接入的完整 Demo 能力。未设置环境变量时兼容旧部署；配置未知值或空值时应拒绝启动，避免误开放。恢复模块先在隔离数据和验收服务上测试，再同步网关、worker 与页面版本；不能仅修改前端开关。原生子智能体配置需要重启 worker 生效。

## 发布与恢复原则

先在独立验收服务测试真实发送、资料及报告、引导/排队/停止、重连、外观与被禁能力的直接调用。正式切换前确认没有活动轮次与待执行队列，再停写并备份数据库及原生 home 成对数据；保留发布包和服务配置。

回退通常恢复旧程序与服务配置，继续使用当前数据；不能用旧数据库覆盖切换后新对话。若确需数据恢复，按 [运行、迁移与恢复](agent-demo-t3-deployment.md) 完成成对校验。切换产品配置不执行历史清理、会话转换或原始偏好覆盖。

## 项目工作区

问答、工作区、部署发布共用顶部项目与模块导航，各自填满顶部栏下的剩余空间。左侧仅保留当前模块自己的会话、文件或服务列表，工作区与部署页不保留空的全局侧栏。工作区只保留内部原始、外部脱敏两类，源码包与服务发布集中到部署页。切换项目或页面不修改已开始对话和发布任务的绑定，未发送草稿及查看状态按用户与项目恢复。

内部示例具有真实独立 Git 历史；公开 HTTPS 仓库导入固定提交，单仓保留原目录。外部文本执行内置凭据和项目替换规则，无法自动检查的文件逐项确认或排除后才发布。新对话固定工作区版本，切换范围另建干净对话；历史会话保留原资料范围。Agent 仅通过授权工具读取文件，不能使用任意主机目录或 shell。

前后端源码 ZIP 直接从内部固定版本生成，含 SHA-256 清单。独立部署验证环境通过 `AUTOOPS_DEPLOYMENT_ENABLED=1` 开放内部管理者的静态前端发布，固定包与配置后交给现有部署引擎和部署 Agent；问答 Agent 的只读权限不变，原 8787 Demo 不因前端入口自动启用部署。真实构建、健康检查及回退证据与未闭环范围见 [独立部署验证](agent-demo-t3-deployment.md#独立验证工作区部署发布28887)。导入仅支持公开托管 HTTPS 地址，当前上限 12,000 文件、64 MiB（包含 Git 信息）、单文件 8 MiB，超过限制会失败并保留已发布版本。

## 技能管理使用与维护

1. 管理员进入顶部“更多功能 → 技能库”，中央库每个技能显示一张紧凑卡片，可导入单个技能的 Markdown、ZIP 或公开 Git 固定提交。多技能 Git 仓库须指定技能子目录；点击技能进入完整文件与版本详情，返回后继续原卡片位置。
2. 在卡片直接点击助手分配、再次点击取消；“项目”在同一卡片展开目标清单，可搜索并逐项选择。新快分配默认仅内部，版本及外部范围通过分配设置调整。项目单独分配优先于同技能的助手分配，取消项目单独分配后沿用助手设置；“助手技能”可按助手查看，“项目技能”使用顶部当前项目，不另设页面级项目选择。中央库与助手分配保留全局作用域。
3. 新建对应项目与助手的对话，输入 `$` 选择技能。点击标签可查看说明；说明内的包内相对文件链接留在同一版本，继续使用 T3 原生文件标签页。
4. 导入新版本后，原分配不自动升级；修改目标分配的版本后，新会话使用新版，旧会话保持已固定版本。撤回分配或停用会拦截新的执行；删除前须撤回全部分配。

当前中央库最多 256 项；每包最多 512 个文件、16 MiB，单文件最多 4 MiB。读工具单次最多返回 256 KiB 文本，并明确截断状态；二进制文件返回元数据和授权链接，不冒充已经读懂内容。脚本和依赖型技能可完整入库和预览，但只有当前只读工具能支持的版本才可分配与调用。

验证脚本为 `test/t3-skill-library.test.mjs`、`test/t3-scoped-skills.test.mjs`、`test/t3-skill-library-live.mjs` 与 `test/t3-skill-library-ui.mjs`。真实模型及浏览器脚本只允许独立验收端口，按本次创建的 ID 清理对象并核对既有目录；不能指向正式 Demo 做破坏性测试。中央库使用 T3 的紧凑卡片和原生 Popover，文件详情按需进入满高工作区，低频操作使用原生菜单和 Dialog。管理机制及分配交互来源与保留原件见 `vendor/skills-manager/`。

### 技能中央库整页风格校正（2026-10-23）

上一版虽然用了 T3 卡片外壳，但整页工具栏、常驻说明和卡片元数据堆叠过多，未形成 T3 的信息层级。本轮采用 `WorkspacePageContainer` 的受控宽度及 `ThemeSettings` 的目录节奏，卡片组合 `ThemeSearchSection` 的表面与原生紧凑 Toggle。锁定 T3 没有现成技能仓库页，`ThemeSearchSection` 本身位于主题导入弹窗；这里属于原生模式的业务组合，不是完整上游技能页面的直接复制。

范围和搜索合并为一组工具栏，导入留在页头；卡片保留名称、简述与直接分配，规则、来源和版本按需查看。正常卡片取消重复状态徽标及技术元数据，未就绪和停用仍可见。1440px 桌面实测内容网格宽 976px、两列，普通卡片高 172px。文件详情、内部／外部范围、版本固定及撤回语义保持原实现。

成功通知使用原生 Toast，避免推移目录。在项目浮层或管理弹窗内连续操作，先更新真实分配状态，关闭后再提示最后一次成功，避免 Toast 争夺 Esc 关闭顺序。取消当前筛选项目的分配会移除卡片，此时清除已卸载浮层的标记，焦点回到可见卡片或“添加技能”，后续通知不会被旧标记阻塞。

### 合入部署模块的共享页面结构（2026-10-23）

基于部署分支 `feat/workspace-deployment-validation` 的 `0c4eac37`，合入技能分支 `feat/skill-management` 的 `15c5ee80`；先在 `feat/skills-deployment-integration` 完成适配和独立预览验证，再将部署分支快进至同一合并结果。保留两条分支的完整提交历史。

中央库和助手分配是全局管理；项目技能直接跟随顶部项目。卡片上的项目选择仍用于分配目标，不能与顶部浏览项目混淆。`skillView` 与授权项目构成可恢复的链接，搜索偏好按用户及项目保存；设置内切项目后返回技能库使用当前项目。显式无效项目不回退到其他项目。本轮沿用共享壳要求有效授权项目的入口前提，没有增加无项目账户的全局管理入口。
