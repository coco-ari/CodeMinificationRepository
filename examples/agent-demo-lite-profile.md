# 项目助手精简版能力边界

本配置用于验证未来工作台的项目助手闭环，UI 与聊天流程仍来自锁定的 T3 Code v0.1.1。本轮收起功能入口与新增执行能力，保留上游源码和依赖，不以删除代码或缩减构建体积作为目标。

## 使用范围

| 模块 | 精简版范围 |
| --- | --- |
| 项目与权限 | 登录、身份、项目/环境、可见性与既有资料授权保留；CPA 由宿主配置，运行权限固定 |
| 输入与执行 | 中文输入、CPA 模型及对应思考强度选择、附件与资料上下文、原生技能搜索/选择/说明及真实调用、草稿/暂存及冲突恢复、流式回复、工具详情、提问/授权、引导/排队、队列编辑/取消、停止、手动 `/compact`、`/model` |
| 阅读与恢复 | Markdown、代码高亮、滚动锚定、历史分页/搜索、断线重连、现有产物与文件下载 |
| 会话管理 | 新建、重命名、置顶、排序、归档/取消归档、删除确认；旧稍后提醒/已处理记录仍可阅读及恢复 |
| 常规设置 | 发送快捷键、后续输入的引导/排队偏好；技能目录与说明、管理员导入/启停工作台共享技能；默认模型/权限/版本只读，实际模型与强度在输入区选择 |
| 外观设置 | 浅色/深色/跟随系统、配对主题、本地新建/编辑/复制/导入/导出、对比度、玻璃透明度、对话宽度、适用字体与字号、字体平滑、换行、数学公式、界面动效与面板动画时长 |
| 暂停新增 | 计划及执行计划、分支对话、历史编辑/回退、子智能体、交互式 HTML/MCP Apps、稍后提醒/已处理自动化、高级发送方式、用量面板、自定义快捷键、系统通知和调试入口 |

旧计划、分支、子任务、HTML 与工具记录仍可阅读。关闭交互式产物的新调用和回传，不删除已保存的静态内容。项目资料读取、Markdown/PDF 报告与附件下载保留。在线主题市场受现有同源 CSP 限制，本轮不展示，也不放宽 CSP。

设置导航只开放常规、外观、归档；开源许可证保留底部入口。自定义快捷键编辑器关闭，T3 核心快捷键及提示保留。外观里的终端、差异对比、工作区上下文和环境身份装饰不适用于本 Demo，不展示。

技能是精简版保留的核心能力。通过原生 `$` 搜索、技能标签、说明预览和原生技能输入调用；默认提供项目资料解读、环境健康检查、发布准备报告。常规中的技能目录支持查看说明，管理员可导入纯文本 `SKILL.md` 并启用/停用；目录为工作台共享，所有项目成员可见，不安装附带脚本或依赖。技能不会扩大当前会话的项目、环境和工具权限。停用后拒绝新的调用，已经开始执行的本轮保留；现有历史记录不被改写。已有显式技能注册表继续按其配置加载，不覆盖为空或自定义的目录。

模型与思考强度使用 T3 原生选择器、草稿保存、`/model` 及快捷键流程。默认仍为 `grok-4.6`；可选目录及每个模型的思考档位来自已配置 CPA 的能力接口，图像/视频生成型号不进入对话选择器。worker 启动时同步并缓存能力元数据，同一 CPA 短暂不可达时可回用上次成功目录；缓存不含密钥。服务端和原生请求均校验模型与思考档位，不能从浏览器切换运行器、接口或权限，也不能把所选模型强制改回默认。模型名称与实际返回型号之间的上游别名映射沿用 CPA 配置；目录声明的档位不等同于每个上游型号的推理效果均已测量。

普通对话不显示空详情；仅有实际历史关联时显示查看入口。没有资料预览时隐藏右侧面板按钮。只读历史使用阅读提示与新建对话入口，不显示无法发送的编辑器。锁定的环境、可见范围及唯一 Agent 以文字显示；新建对话仍可选择环境与范围。不提供未适配的 T3 提示词分享链接和普通用户对话 ID 复制入口。

“外观 → 动画 → 界面动效”默认跟随系统，也可显式开启或关闭。显式开启允许 Windows 关闭动画而工作台仍播放原生等待与界面动效；关闭时不播放动效。设置沿用当前账号在此浏览器中的偏好存储，刷新保留；“恢复默认”恢复跟随系统。面板动画时长独立设置，默认 0 ms，不因开启动效自动增加布局动画。后台、不可见活动仍暂停，高对比度模式仍保留可读的静态状态。

## 能力与偏好

`AUTOOPS_DEMO_PROFILE=project-assistant-lite-v1` 是部署时显式选择。`agent-demo/t3-adapters/product-profile.mjs` 是服务端能力与有效设置的来源；宿主 bootstrap 将配置传给界面，RPC、HTTP/MCP、原生 Codex 配置同时约束执行。不能通过旧客户端、深链或隐藏入口发起已关闭能力。

精简版强制按已完成段落流式显示，关闭自动恢复受限轮次、自动稍后提醒、自动整理、重启后继续执行和 Claude 空闲压缩。删除始终确认。覆盖的是有效设置，不改写用户原有隐藏偏好；外观、发送快捷键和后续输入偏好按用户选择生效。“恢复默认”仅恢复精简版开放的可编辑字段，不清空暂存、主题库或隐藏偏好。

`t3-demo-full-v1` 保留此前已接入的完整 Demo 能力。未设置环境变量时兼容旧部署；配置未知值或空值时应拒绝启动，避免误开放。恢复模块先在隔离数据和验收服务上测试，再同步网关、worker 与页面版本；不能仅修改前端开关。原生子智能体配置需要重启 worker 生效。

## 发布与恢复原则

先在独立验收服务测试真实发送、资料及报告、引导/排队/停止、重连、外观与被禁能力的直接调用。正式切换前确认没有活动轮次与待执行队列，再停写并备份数据库及原生 home 成对数据；保留发布包和服务配置。

回退通常恢复旧程序与服务配置，继续使用当前数据；不能用旧数据库覆盖切换后新对话。若确需数据恢复，按 [运行、迁移与恢复](agent-demo-t3-deployment.md) 完成成对校验。切换产品配置不执行历史清理、会话转换或原始偏好覆盖。

## 项目工作区

工作区管理使用 T3 原生页面与组件，提供内部原始、外部脱敏、部署发布三个入口。内部示例具有真实独立 Git 历史；公开 HTTPS 仓库导入固定提交，单仓保留原目录。外部文本执行内置凭据和项目替换规则，无法自动检查的文件逐项确认或排除后才发布。新对话固定工作区版本，切换范围另建干净对话；历史会话保留原资料范围。Agent 仅通过授权工具读取文件，不能使用任意主机目录或 shell。

前后端源码 ZIP 直接从内部固定版本生成，含 SHA-256 清单；目标服务器的构建部署不在此 Demo 中标记为已完成。导入仅支持公开托管 HTTPS 地址，当前上限 12,000 文件、64 MiB（包含 Git 信息）、单文件 8 MiB，超过限制会失败并保留已发布版本。
