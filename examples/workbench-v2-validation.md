## 2026-10-21 范围调整与实测

第一轮仅平台内置 Agent；外部用户主机 Agent、接入认证、心跳与能力上报、中心中继和会话转发，以及相关主机执行隔离后置。平台项目权限、私有/共享会话隔离、只读问答及既有正式部署 Agent 仍保留。原始设计文档和配套图继续约束 UI；当前范围见 [需求补充](workbench-v2-requirements.md)。

任务用于查看执行进度、结果和日志；操作记录用于追溯操作者、对象、时间和结果。“任务与审计”入口包含“任务”和“操作审计”两个页签。旧表格中的“用户主机登记”“两种 Agent”“外部 Agent 能力”等不再是第一轮验收条件。

已移除外部 Agent 的初始样本、创建/连接入口、主机配置和会话执行分支。管理员仅创建和配置平台 Agent，成员使用获授权的共享 Agent。旧浏览器数据保留历史记录，但外部 Agent 不出现在管理、会话、任务、通知和审计中；旧会话链接不可进入，运行任务停止并持久化、排队输入取消，不生成新输出。

本轮实测：核心浏览器 11 组、平台 Agent 9 组、Agent 范围与边界 8 组，共 28 组通过，无未处理的页面异常或控制台错误；TypeScript、Vite 构建、涉及源码与测试的 Prettier 检查通过。核心检查首次在开发热更新期间捕获临时资源错误，改用 `http://127.0.0.1:5174/prototype.html` 的构建预览完整复验后通过。旧数据停止状态持久化由最后一轮边界检查覆盖。已人工查看桌面概览、桌面会话和手机会话截图；本次未重复执行其余未改动模块的独立套件，不代表需求或视觉设计获得用户验收。

## 2026-10-20 按设计反馈修正（范围调整前记录）

原始设计文档与配套图继续有效。本轮将资料集中为“资料与配置”工作区，恢复中性配色、紧凑导航、文档常驻阅读区、产物来源链与详情侧栏、独立发布确认工作区、三栏 Agent 会话和阶段任务详情。后续讨论确认的即时保存、最新文档、全局机柜等业务规则保留。

截图以 1440px 桌面和 390px 手机为主，另检查 768、1280、1920px 布局边界、减少透明效果和高对比度。已人工核对概览、资料、产物、发布、会话的截图，修正筛选区换行、正文空白和手机详情滚动过长等问题。截图在 `.test-artifacts/prototype-v2/design-review/`，对照原图使用；这仍不是用户的视觉验收结论。

当时最终复测：核心 11 组、核心边界 6 组、资料 7 组、Agent 10 组、Agent 边界 4 组、机柜 11 组、跨页面与响应式 7 组通过，各套件无未处理的浏览器异常或控制台错误。16 项纯逻辑检查、TypeScript、Vite 构建、原型源文件格式检查和 `git diff --check` 通过。新增检查包括失效产物不替换来源、带入会话的上下文、私有会话直接 URL、日志不提前显示成功、检索后仍复制/下载完整已加载日志，以及手机输入区和抽屉。页面只是模拟原型，实际服务端与外部系统没有接入。

## 原型边界（沿用项，Agent 范围以上述最新调整为准）

- Git、外部连接、发布、Agent 推理和机柜数据库操作使用虚构样本和可选演示结果；不连接真实基础设施。生产实现和正式技术选型尚未开始。
- 上传内容、编辑、浏览器持久化与文件下载实际生效。一般资料/附件单文件 2 MiB 是原型存储限制；机柜照片最长边压缩至 1600。浏览器存储不足时明确提示未能持久保存，新改动仅保留在当前页面内存中。
- 权限在原型界面及状态转换中呈现；localStorage 不是正式鉴权和秘密存储机制。会话与任务在浏览器打开期间模拟运行，刷新可恢复。
- 已有历史的 Agent 不直接改共享到另一个项目，需新建 Agent；私有与原项目共享之间切换会同步影响旧会话，并先展示影响。
- 旧线上静态站点尚未更新。本次交付为当前分支源码与本地可运行原型，未执行 Git 提交、推送或外部发布。

## 复验与截图

下列命令是完整复验方式；2026-10-21 实际执行的范围见上文。Agent 用例已按仅平台内置 Agent 的范围更新，其余旧记录不能自动计为本轮复验结果。

```bash
pnpm dev:prototype
# 另开终端
pnpm build:ui
pnpm test:prototype:logic
pnpm test:prototype
pnpm test:prototype:design
```

需要 Node.js 24+ 和 Chrome/Edge，可用 `BROWSER_PATH` 指定浏览器。测试截图及下载检查文件写入忽略目录 `.test-artifacts/prototype-v2/`，不作为源代码提交；子目录 `core`、`core-edge`、`materials`、`agents`、`agent-edges`、`cabinet`。

主要实现位于 `web/src/prototype/v2/`；入口 `web/src/prototype/main.jsx`。共享状态和模拟任务在 `store.jsx`；页面边界在 `App.jsx`；资料、Agent、机柜分别独立模块；配置、资源、发布与审计在 `operations.jsx`。旧 `web/src/prototype/` 同名模块保留为首版存档，已不被新版入口导入。
