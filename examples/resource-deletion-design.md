# 创建与删除闭环

更新：2026-10-29。依据用户本次确认：能创建的业务对象必须能删除；删除前确认，删除对象时一并清理归属于它的数据，不以历史引用或将来可能有用阻止删除。本设计替代旧文档中的“先手工解除全部引用”“保留已删除对象全部版本”要求。

## 操作与范围

沿用锁定 T3 的行内操作、更多菜单及确认 Dialog，不新增页面壳。确认展示对象名、级联范围和不可恢复含义；取消不发请求。服务端仍校验当前管理权限、所属项目和修订，避免删错对象。客户端在成功后刷新实际列表，失败显示原因，并沿原请求继续，不能把界面隐藏当成物理删除。

| 对象与入口 | 一并删除 | 独立资源 |
| --- | --- | --- |
| 全局账号列表 → 删除 | 登录与密码记录、本人会话/附件/成果、提供的助手、电脑接入、项目成员关系 | 项目、其他用户及其独立资源保留；删除最后一个有效平台管理员前需另建管理员 |
| 全局/项目目录 → 删除项目 | 项目会话及正文事件、环境/成员、助手及分配、凭证/MCP、仓库连接、工作区原件/捕获/包/任务、自动更新计划、部署配置/记录 | 全局节点、其他项目、其他项目仍在使用的全局 skill 不删除 |
| 项目设置 → 删除环境 | 环境会话、绑定助手与MCP、部署位置/任务/日志/版本及节点绑定 | 项目本身、其他环境、共享服务和独立节点保留 |
| 项目助手/我的助手 → 删除 | 预设、配置版本、分配、共享关系、执行授权、skill 分配及旧配置收据 | skill 包、其他助手、电脑实际文件保留 |
| skills → 更多 → 删除 | skill 包目录、定义与所有启用/分配关系 | 其他 skill 与助手保留 |
| 项目成员 → 移除 | 成员关系、环境授权与该成员的助手分配 | 全局账号保留 |
| 仓库连接/工作区来源/文件 → 删除 | 对应来源、同步记录、当前文件或目录子树、相关固定捕获与输入、派生工作区版本/包及无引用原件 | Git 远端仓库、其他来源和独立文件保留 |
| 凭证 → 更多 → 删除 | 所有密文版本、历史记录；清除仓库凭证关联及使用该凭证的MCP连接 | 仓库连接本身保留，后续使用需配置有效凭证 |
| 环境MCP → 删除 | 连接配置版本、测试记录、运行引用及旧配置收据 | 真实外部服务保留 |
| 工作区更新设置 → 删除更新计划 | 自动更新计划、规则、执行记录，取消本计划未完成工作 | 当前工作区文件保留 |
| 个人设置 → 电脑/登记目录 → 删除 | 对应注册、能力记录、依赖该运行来源的个人助手 | 用户电脑上的真实目录和文件保留 |
| 部署 → 更多 → 删除服务/当前部署位置 | 所属配置、任务、日志、版本记录和无其他引用的中心源码包 | 不通过删除管理记录隐式卸载远端已运行程序 |
| 平台节点 → 删除 | 接入身份、节点绑定、所属部署位置/任务/日志/版本与无引用原包 | 物理服务器及其外部程序保留 |
| 会话列表 → 删除 | 原生停止和附件清理后清除消息、事件、运行上下文、业务输入/成果和绑定 | 其他会话仍使用的独立输入/共享底层数据保留 |

生成的报告、日志、捕获、版本和任务归所属会话、来源或部署对象管理，删除所属对象时同步回收，不留下只能在数据库手工清理的孤儿记录。外部工作区仍只维护一份当前内容，无历史发布与复核流程。

## 执行与恢复

- 各模块通过自身公开删除接口清理自己的表和文件；项目、环境、账号在组合根协调，不让前端逐个解除关系，不跨模块直接写表。
- 执行中的本地资料任务先取消并等待结束，防止迟到结果重建目录。已领取的远端部署允许回传最终结果；清理未完成时明确返回可继续状态，不释放仍被执行占用的对象，也不假称远端已停止。
- 会话沿 T3 持久删除队列完成停止、附件等清理后再清正文和事件。删除项目/账号等待该阶段，不只修改软删除标记。
- 只保留恢复与去重所需的最小删除结果/请求标识，不保留被删对象的配置、正文、密文或历史副本。相同删除请求重试不能误删后来创建的新对象。真实失败不吞掉，权限撤销时停止后续动作。
- 共享底层文件只有在仍属于其他未删除对象时保留；这属于其他对象的正常数据，不是被删对象的历史归档。删除平台记录和删除外部资产是不同操作，确认文案必须写清。
