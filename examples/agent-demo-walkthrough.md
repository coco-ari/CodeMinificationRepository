# Agent 交互 Demo 体验说明

打开 [测试机 Demo](http://192.168.31.157:8787/agent-demo.html)，使用 `admin` / `Demo123!` 登录。同一 ZeroTier 网络也可使用 [ZeroTier 入口](http://172.29.22.6:8787/agent-demo.html)。更新后请强制刷新一次。

已接入 `grok-4.6（CPA）`，由测试机上的 Codex App Server 执行。新建会话时选择“真实运行 · grok-4.6（CPA）”，即可使用真实模型。原“场景演示”仍可用于对照固定交互时序。项目资料和环境快照目前是演示数据，不代表生产环境实时状态。

## 建议体验顺序

1. 新建会话，选择 AutoOps 工作台、测试环境、项目助手、私有会话，并把运行模式设为“真实运行 · grok-4.6（CPA）”。会话固定这些上下文；以后切换环境需要新建会话。
2. 输入“先问我检查范围，再生成测试环境检查报告”。观察模型的工具进度与澄清卡，选择或填写回答，随后查看生成结果和资料引用。
3. 点击回答中的资料链接，打开授权文档预览。在右侧“结果”查看报告；手机通过右上角上下文按钮打开抽屉。
4. 再发起一轮检查。执行中补充文字，选择“引导本轮”或“排队”；队列可以编辑、调整顺序或删除。真实模式中的引导会提交给当前运行器轮次；查看后续回答是否采纳你的补充。场景模式仅验证接收与显示时序。
5. 在有排队消息时点停止，确认部分回答仍保留、队列暂停。“继续”接着已有结果发起新轮；“恢复队列”让排队消息继续执行，两者独立。
6. 输入一段未发送文字，切换会话或刷新，确认草稿仍在。上翻查看旧消息时，新输出不应把阅读位置强制拉到底部。
7. 上传一个 Markdown 或纯文本文件，检查预览、带附件发送与结果查看。可上传下载其他文件，不代表模型能读取所有格式。
8. 运行中的发送按钮旁有菜单，可以切换引导或排队，并记住个人选择。桌面 Ctrl/Cmd+Enter使用另一种方式，手机Enter仍换行。
9. 回复下方可重新生成，或编辑用户消息后创建分支；原对话保留。“分支”按钮本身只复制历史或恢复草稿，不自动调用模型。
10. 对话右上角搜索正文及思考；显示菜单可隐藏思考、自动展开及导出Markdown。没有模型思考事件时只展示真实执行状态。
11. 历史列表支持正文检索、个人置顶与归档，归档入口可以恢复。长会话先显示最近30轮，加载和搜索都能揭示更早内容。

普通场景按固定时间较快结束，适合观察流式显示；澄清等待期间可以从容查看队列与控制项。自动化验收另外使用可控的长运行、失败和延迟场景覆盖竞态，结果见 [验收记录](agent-demo-validation.md)。

## 会话权限

`admin` 与 `lin` 都是 AutoOps 工作台成员；`admin` 与 `chen` 都是机柜项目成员，三个账号的演示口令相同。可以通过退出后切换账号对照检查：

- 私有会话只对创建者显示。
- 项目共享会话对对应项目成员显示。
- 未发送的草稿和附件仍属于本人；附件在消息或队列被接受后，才按会话范围共享。

测试脚本只清理自己创建的验收会话，保留用户的体验内容。

## 如何判断这版体验

关注操作是否有及时反馈、文字是否丢失、停止是否真实反映状态、阅读位置是否稳定，以及错误后是否能继续。性能数据、截图、发现过的失败与未验证项均记录在 [验收记录](agent-demo-validation.md)，项目接入方向见 [技术方案](agent-demo-technical-plan.md)。

真实 Grok 已验证资料读取、澄清与同轮引导、排队启动和停止的网页流程。新增操作的受控及部署后证据分别列在验收记录，不能将受控事件等同实际模型表现。实体手机软键盘及用户主观体验仍需实际确认。
