# 工作台导航与配置体验验证

日期：2026-10-29。基线 `bc5dfa6b`，分支 `feat/workspace-deployment-validation`。设计与五个开源项目调研见[工作台导航与配置体验](../../examples/workbench-navigation-design.md)，视觉沿用锁定 T3 v0.1.1 `fe27e8e3`。

## 问题与实际修改

原项目管理侧栏列出全部项目，全局账号、平台节点、个人助手混在项目上下文，项目配置和助手页存在两套编辑入口。已改为独立全局工作台与明确项目模块，项目设置侧栏只负责本项目配置分组；全局面包屑不再显示最近项目。保留合法深链、项目授权、设置返回和自适应导航，导航完成前不提前写入项目选择。

项目和个人助手编辑改为页面表单，保存/取消固定在顶部，行内开关直接启停。共享配置仍归提供者管理，分配仍归项目；旧电脑来源编辑保留原来源、目录、模型与强度。草稿离开给出页面内选择，未知保存沿原请求查询，失败恢复不重复写入。

skills 全局和项目分开管理；上层继承只读显示。定向用例复现了电脑助手被中央目录错误展示为“已继承”，已筛出电脑目标并在范围说明明确其使用本机 skills。此修正不新增平台资料/MCP 桥，也不宣称电脑运行器已支持中央 skill。平台节点复用原公开模块的整页变体，项目环境继续原节点绑定流程。

## 同条件操作变化

| 任务与初始条件 | 修改前 | 修改后 |
| --- | --- | --- |
| 项目设置列表中停用一个本人可管理助手 | 编辑→取消启用→保存，3步 | 行内开关，1步；仍等待原服务确认 |
| 当前项目管理另一个项目 | 当前项目名下选择其他项目，1步但归属混淆 | 项目选择器展开→选择，2步；或工作台→打开项目，2步 |
| 当前项目进入本人电脑/助手管理 | 助手→我提供的，2步，仍挂当前项目名 | 工作台→我的助手，2步，明确全局归属 |
| 编辑助手并保存字段 | 编辑→填写→保存，3步，弹窗内部滚动 | 编辑→填写→保存，3步，整页分组和固定操作栏 |
| 项目目录寻找目标 | 在侧栏扫描全部名称后点击 | 搜索→打开，2步；空结果有清晰反馈 |

启停减少两次点击，没有声称减少网络服务处理时间；编辑和管理入口主要改善归属、滚动及可发现性。共享、删除和实际未知结果仍保留必要状态与恢复操作。
