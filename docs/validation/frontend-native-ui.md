# 前端原生组件统一

本批按 2026-10-31 用户确认的 T3 风格完成全站基础组件统一和旧前端退出；目标与约束由 [T3 UI 规范](../../examples/t3-ui-standard.md)维护。源码基线为 `15f38818`，固定候选及虚拟机回执在本记录末尾补齐。

## 实现范围

复用锁定 T3 `fe27e8e3dc12dcbb108e9a28fd9b8cb65f34ae92` 的 27 个共享组件，实际运行使用已锁定的 Base UI 1.5.0。沿用 `AppSidebarLayout`、`ModuleWorkspace` 和 52px 顶栏，保留中文化、业务尺寸变体及授权、任务绑定和恢复合同。

- 删除 7 个 Radix 运行适配模块和不再使用的折叠动画样式；原有 3 份适配层行为测试迁移为原生组件行为测试。
- 同步复选、单选、选择器、模型工具栏、菜单、弹窗和滚动容器的全部调用方。选择器显式提供显示标签，助手分配保留不可用原因；表单继续使用真实受控输入。
- 修复原生选择器长列表、滚动区域高度约束、数值完成回调边界、环境 MCP 弹窗初始焦点、相邻问答菜单及客户文件引用后的焦点恢复。
- 源码包弹窗返回实际的“服务操作”入口；全局节点整页返回接入入口。配置页返回部署时恢复原环境中的服务、目标、任务与页签，重新在当前授权列表中匹配；显式路由优先，不自动提交任务。
- 删除旧后台、旧问答、Solid Glass 与原型共 134 个前端文件及 44 份专属测试和夹具。当前工作台及服务端能力保留；客户电脑、部署 Agent 和实际协议实现不在删除范围。
- 构建只保留 `agent-demo.html` 工作台入口，开发和预览根地址同样进入该入口。清理专属依赖和两个锁文件，没有引入新依赖版本；部署只替换网页产物。
