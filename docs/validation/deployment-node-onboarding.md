## 实现范围

- 环境节点弹窗提供管理／接入和配置入口；完整节点页按连接、项目与环境、存储分组。路由保留来源项目和环境，支持刷新、前进后退、存储分组定位和返回原环境。环境内展示存储摘要，管理员统一到节点页编辑。
- 接入先说明服务器和 HTTPS 要求，按部署配置提供公开 CA 和指纹。命令使用独立临时文件，页面只按实际注册及心跳更新；可见时每 5 秒刷新。未注册节点可更新口令，旧口令失效，持久回执和浏览器记录不保存口令。
- 分配一次事务完成项目授权及多个环境绑定，保留仅授权项目和暂不分配。现有授权、环境权限、版本及请求标识均在服务端校验；撤回和解绑仍是独立操作。
- 存储设置允许离线、忙碌或未分配时保存，展示保存版本、应用版本、等待原因和脱敏错误；刷新保留草稿，冲突要求重新核对，降低预算提示清理影响。
- 安装器先下载和构建，再创建持久目录；失败只回收本次创建且未启动的内容，已有 Agent 身份和启动结果未知的材料继续保留。
