## 实际变化

- 业务范围从外接叠层移入 `ChatComposer` 的原生工具栏，共用一个输入表面，不再叠加第二张配置卡片。
- 控件按环境、资料、助手预设、模型／思考强度、附件和发送排列。按输入区实际宽度布局，宽屏同行，窄屏范围一行、模型和操作一行。
- 默认入口为“助手预设”，菜单只列真实助手。平台预设可“取消使用预设”，电脑来源可“改用平台问答”；沿用原有范围保护和干净草稿流程，不引入新的执行模式。
- 范围控件使用共享控件的正常对比度，固定文字槽位、长值省略、完整说明和键盘访问保留。受限参数与已接受会话继续只读。
