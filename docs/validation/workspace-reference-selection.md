# 工作区源码来源引用选择

2026-10-29，修复内部工作区“添加/编辑源码来源”只能手填分支的问题。业务约束见[工作台设计](../../examples/project-workbench-design.md)，本批只修改引用选择交互，不改变仓库连接、凭证、同步或部署权限。

## 行为

选择已登记的项目仓库后，使用现有、经过项目授权的 refs API 查询远端默认分支、分支和标签。分支及标签可通过下拉箭头展开、输入搜索、鼠标或键盘选择；远端默认分支展示实际名称，提交 SHA 保留手填。查询失败显示局部错误并提供重试，手填仍可用；截断结果明确提示，候选较多时可搜索。

切换仓库或引用类型清空引用，保留挂载目录等其他草稿。刷新保留当前输入；关闭弹窗、切换仓库取消旧查询，迟到结果不能覆盖新仓库候选。保存沿用原有工作区使用配置接口，不写项目仓库连接。

选择控件复用锁定 T3 的 `ui/autocomplete` 样式及 Base UI 原生运行时；列表挂到所属弹窗内部，避免现有模态层拦截点击。相同输入场景从“去仓库找名称、复制、回填”变为“展开或搜索、选择”；不改变保存、同步等后续步骤。
