# 技能库与部署日志交互优化验收

日期：2026-10-28。独立分支：`feat/t3-ui-skills-deployment`，基于已交接的 `d40769e2`。本记录只覆盖用户确认的两项后续 UI 优化，不替代主任务验收清单；合并和测试站部署留待主任务完成后进行。

## 范围与复用

- 技能库：`SkillLibraryPage.tsx` 将原搜索状态和语义入口移到列表工具栏，列表滚动或侧栏收起时仍可查找；清空后回到搜索框。`SkillLibraryCard.tsx` 将长名称展示为最多两行。保留原目录读取、助手/项目直接分配、详情返回及授权处理。
- 部署：`deployment/DeploymentLogs.tsx` 将任务已报告的阶段及展开后的阶段记录接到现有日志筛选；支持清除筛选并恢复输入焦点。阶段比日志先到达时也可选择，补读状态及导出保护保持有效。
- 参考固定 T3 `fe27e8e3dc12dcbb108e9a28fd9b8cb65f34ae92`：`ThemeSearchSection` 的目录搜索组合、`fileSurfaceChrome` 的紧凑工具栏与内容优先布局。继续使用原生 InputGroup、Button、Collapsible、Select、ScrollArea，不引入依赖或另一套样式系统。
- 调用链仍为页面 → 已有目录/部署读取接口 → 原业务合同。没有修改 `useSkillLibraryCatalog`、助手预设、后端接口、轮询游标、部署执行或恢复逻辑。阶段按钮筛选同名阶段的日志，不根据时间戳推断阶段成功，也不把阶段名改成新的业务状态。

## 修改前复现与原因核对

| 问题                                     | 可验证原因                                                            | 证据与结论                                                                                                              |
| ---------------------------------------- | --------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 侧栏收起后无法直接搜索技能               | 搜索仅在 `SkillLibraryPage` 的 `ModuleSidebar` 中，随侧栏退出可视区域 | 1440×600 浏览器复现：目录有 18 项，搜索输入框与视口交集为 0；390×600 同样无可见搜索入口。移动到列表工具栏后原用例通过。 |
| 同上                                     | 权限或目录读取失败导致入口缺失                                        | 同一夹具 `canManage=true`，目录读取成功且卡片可见，排除此原因；原有撤权与失败重试用例继续通过。                         |
| 展开部署阶段后仍要通过下拉框另选日志阶段 | `DeploymentLogs` 的阶段历史是静态文本，已结束任务还隐藏当前阶段       | 修改前含构建、切换、验证三阶段及三条日志，新增用例停在缺失的阶段按钮；改后可直接筛选并保持下拉框一致。                  |
| 同上                                     | 服务端尚未提供阶段或日志                                              | 同一夹具已含完整阶段记录和对应日志，排除数据缺失；另验“阶段先到、日志仍在补读”，没有错误显示为无日志或提前允许导出。    |

复现先于实现修改。初次测试夹具未安装完整宿主、文本断言方式不合适，修正后才保留上述有效失败证据。新 worktree 依赖按锁文件离线校正，锁文件没有变更；安装过程及测试夹具问题不计为产品缺陷。

## 同条件步骤对比

每次点击、菜单展开、选项选择、一次文本输入分别计一步。技能比较从侧栏收起、目录已载入开始；日志比较从已读完所选任务开始。正文与分配均保留原权限及请求条件。

| 核心任务                                 | 修改前                                             | 修改后                                       |
| ---------------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| 桌面查找技能并阅读结果                   | 展开侧栏 → 点击搜索 → 输入关键词，3 步             | 点击搜索 → 输入关键词，2 步                  |
| 窄屏查找技能并阅读列表                   | 展开侧栏 → 点击搜索 → 输入关键词 → 关闭侧栏，4 步  | 点击搜索 → 输入关键词，2 步                  |
| 桌面搜索后查看正文、返回并分配项目       | 上述 3 步 → 打开技能 → 返回 → 点击项目，6 步       | 上述 2 步 → 打开技能 → 返回 → 点击项目，5 步 |
| 清空关键词后继续浏览（焦点已离开搜索框） | 点击搜索 → 全选 → 删除，3 步                       | 点击清空，1 步并恢复搜索焦点                 |
| 查看任务当前阶段日志                     | 展开日志阶段 → 选择对应阶段，2 步                  | 点击任务阶段，1 步                           |
| 展开历史后查看某个阶段日志               | 展开执行阶段 → 展开日志阶段 → 选择阶段，3 步       | 展开执行阶段 → 点击阶段，2 步                |
| 同时清除日志关键词与阶段                 | 点击搜索 → 全选 → 删除 → 展开阶段 → 选择全部，5 步 | 点击清除筛选，1 步并恢复搜索焦点             |

搜索与日志筛选均在已加载数据内完成，新增网络等待为 0；用例检查这些操作没有增加读取请求。正文读取、分配和日志补读仍等待原接口。本批没有测量真实 4G 延迟，不把隔离浏览器的耗时当作真实网络性能。

查看技能正文时仍以文件内容为主，返回列表后继续搜索；不在正文内新增第二套目录搜索。详情返回保留搜索条件、列表位置和原卡片焦点。
